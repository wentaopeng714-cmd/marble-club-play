# 滚珠俱乐部 · MARBLE CLUB

这是可直接打开试玩的网页发布仓库，仅包含打包后的浏览器文件，不包含完整开发工程或比赛服务器。

玩法：五轮单人淘汰赛、自由试跑、AI 观赛竞猜和弹珠收藏。金币仅为游戏内虚拟金币；存档保存在当前浏览器中。当前发布版尚未接入真人联机服务。

操作：A/D 或方向键转向，W 推进，S 刹车，空格跳跃，R 回到检查点，E 使用冲刺，C 切换视角。

独立练习作品，与参考作品及其作者没有官方关联。
